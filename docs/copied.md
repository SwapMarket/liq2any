# Code copied from liq2sol

liq2any copies liq2sol's code instead of depending on it (user's decision, 2026-11-22), so changes here never touch liq2sol's live
repository. This file records each copy, so it can be compared with liq2sol later.

| Here | From `SwapMarket/liq2sol` | At commit | Changes since copying |
|---|---|---|---|
| `contracts/swapkey/` | `contracts/swapkey/` | `75d1722` | Crate renamed `liq2any-swapkey`, and its tests' imports to match. Added `polygon_address_of`, `polygon_value`, `secret_from_polygon` and `tests/polygon.rs`, with `sha3 = "=0.12.0"` for keccak. `refund.simf` is unchanged, byte for byte. |
| `shared/chain/src/{liquid,esplora,swap}.rs` | `shared/chain/src/` | `75d1722` | Crate renamed `liq2any-chain`. `check_genesis` takes Polygon's chain id instead of Solana's genesis hash, with `POLYGON_MAINNET_CHAIN_ID` in place of `SOLANA_MAINNET_GENESIS`. Comments name Polygon. `sol.rs` is not copied; `evm.rs` and `polygon.rs` are new. |
| `shared/chain/tests/{backoff,confidential,forged_asset}.rs` | `shared/chain/tests/` | `75d1722` | Imports renamed. `network.rs` is rewritten for Polygon; the Solana-only tests are not copied. |
| `maker/core/src/{lib,store}.rs` | `maker/core/src/` | `75d1722` | Crate renamed `liq2any-maker-core`. The store drops the tables for closing Solana escrows and remembering vanished ones (an EVM lock never disappears), counts costs in POL gwei instead of lamports, and the signer's ledger gains a `nonces` table: one call per nonce, forever. |
| `maker/core/src/{engine,policy}.rs` | `maker/core/src/` | `75d1722` | Rewritten on the same structure for Polygon: both clocks on every lock, combined by leg; gates on both of the taker's clocks; finality lag and block rate in the health check; Tether's blocklist; the gas drop; `extend` on both clocks; the EVM nonce rule. |
| `maker/core/tests/` | `maker/core/tests/` | `75d1722` | Ported to Polygon case by case, with new cases for each rule above. `store.rs`'s two Solana-only tests are dropped. |
| `maker/signer/` | `maker/signer/` | `75d1722` | Crate renamed `liq2any-signer`. The Liquid half (wallet, fee coins, sessions, Liquid lock, claim and refund, withdrawals) is unchanged but for key-derivation tags, now `liq2any-…`, so keys never coincide with a liq2sol maker's. The Solana half is replaced by Polygon: locks, claims, refunds, `extend` and `release` through the escrow, the nonce rule with fee bumps, simulation before a nonce is taken, `ApproveEscrow` and `PendingPolygon`. Escrow closing is gone, and the Solana vault with it; an optional `MakerVault` (`polygon.maker_vault`) takes its place. |
| `maker/signer/tests/process.rs` | same | `75d1722` | The same attacks through the socket, with a local `anvil` chain carrying the real escrow and stand-in token in place of Solana devnet, plus Polygon's: both clocks, the gas drop, the blocklist, approval, nonces and fee bumps. |
| `deploy/signer.example.json` | same | `75d1722` | Polygon settings, pointing at the Amoy deployment, in place of Solana's. |
| `shared/rfq/` | `shared/rfq/` | `75d1722` | Crate renamed `liq2any-rfq`, version 3 (docs/design.md section 5): directions are `from`/`to` pairs of chains; the offer lists `chains` and priced `pairs`; quotes and terms carry the gas drop in wei; accepts carry the taker's Polygon address and `gas_to`; terms carry the escrow, token, chain id and `polygon_window_secs`, which the taker holds to pinned values. Transport, wrapping, sessions and rate limits are unchanged. Tests ported case by case; one check on ciphertext was made exact, because random base64 contains "rfq" about once in 250 runs (also so in liq2sol). |
| `Cargo.lock` | `maker/Cargo.lock` | `75d1722` | Started from the maker's lock, a superset, so shared dependencies keep liq2sol's versions. Updated by cargo as crates were renamed, added (`sha3`, `secp256k1`'s `recovery` feature) or dropped (Solana). |
| `deny.toml` | `deny.toml` | `75d1722` | None |
| `client/` | `client/` | `75d1722` | AGPL-3.0-only, as there. The WASM's Solana half (`solana.rs`) is replaced by Polygon calls built with the shared Rust the maker signs with (`shared/chain/src/polygon.rs`, now built for the browser too), and checked against Foundry's `cast` (`wasm/tests/parity.rs`); its Liquid half is unchanged. The page reads and writes RFQ v3, talks to Polygon over JSON-RPC at `finalized` on two endpoints, connects EVM wallets through EIP-6963 or WalletConnect's `eip155`, approves and locks P→L on both clocks, and claims L→P only with 30 min left on both. Rent reclaiming, the Wallet Standard, Solana's transaction formats (`txformat.js`) and wallet deep links (`openin.js`) are gone. `test/drive.mjs` drives it against the daemon, the regtest node and anvil, with a test wallet that sends through anvil. The logo is redrawn by `scripts/make-logo.py` (copied too), and `polygon.svg` is drawn here. `reproducible/` builds the published page (`scripts/build-page.sh`). |
| `deploy/{install,update,install-elements,withdraw-usdt}.sh`, `deploy/*.service`, `deploy/*.gpg` | `deploy/` | `75d1722` | Renamed `liq2any`. `install.sh` makes no Solana wallet and takes no Helius key, since the signer makes the Polygon key; it defaults to testnet, and takes `--maker-vault`. `withdraw-usdt.sh` names Polygon. The release key is SwapMarket's same key, byte for byte. `deploy/README.md` is rewritten for Liquid testnet and Amoy. |
| `scripts/{build-page,check-page,sign-release,test-install-elements,test-withdraw-usdt}.sh` | `scripts/` | `75d1722` | Renamed `liq2any`; the withdraw test names Polygon. |
| `.github/workflows/{release,pages,deploy-scripts}.yml` | same | `75d1722` | Renamed. The release builds the root workspace, and its notes say test networks only. The page's tests are every `client/test/*.test.mjs`, and its paths drop Solana's programs and add the Amoy deployment record. The audit and real-chain suites are not copied yet. |
